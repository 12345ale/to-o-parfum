Guía rápida para administrar el catálogo antony Parfum.

01

Agregar fragancia

En Inicio, completa el nombre, categoría y estado del producto. Presiona “Guardar fragancia”.

02

Consultar colección

En la sección Colección puedes revisar los productos registrados y su disponibilidad.

03

Editar información

Presiona “Editar” en la fila del producto, modifica los datos y guarda los cambios.

04

Eliminar una prueba

Usa “Eliminar” únicamente con productos ficticios. El sistema pedirá confirmación.

05

Consultar la API

Abre /api/productos para ver el catálogo en JSON. La API permite GET, POST, PUT y DELETE.
